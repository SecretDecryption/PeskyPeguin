PESKY PENGUIN - VERCEL UPLOAD

1. Extract the ZIP first.
2. Upload or deploy the entire extracted folder, not only index.html.
3. If Vercel asks for a framework, choose Other.
4. Leave Build Command and Output Directory blank.
5. Deploy to the pesky-penguin.vercel.app project.

The sharing preview uses the centered Pesky Penguin logo with wide safe margins
so the artwork remains visible in square, portrait and landscape link cards.
No environment variables are needed.
