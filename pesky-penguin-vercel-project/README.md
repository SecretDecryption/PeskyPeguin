# Pesky Penguin Frozen Treats - Vercel Project

This package is ready for Vercel as a standard Next.js project.

## Deploy with Vercel

1. Extract this ZIP.
2. Put the extracted files in a GitHub repository.
3. In Vercel, choose **Add New Project** and import that repository.
4. Leave the detected framework as **Next.js** and select **Deploy**.

No environment variables or database are required.

The location section includes separate **Apple Maps** and **Google Maps** links.
